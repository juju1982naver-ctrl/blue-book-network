# 공개 차수순 발행 규칙 — 기존 주제 표시 순서보다 우선

제1차부터 시작해 제2·3·4·5·6차로 진행한다. 차수별 준비 자료는 ORDERED_RELEASE_01.json부터 ORDERED_RELEASE_06.json에 있다. 포털 목록을 다시 수집하거나 후속 차수부터 먼저 발행하지 않는다.

## 한국어 운영 규칙
- 1차 자료부터 순차적으로 진행한다. 현재 차수의 준비 주제를 처리하기 전 다음 차수를 주제로 발행하지 않는다.
- referenceReady=true인 준비 묶음부터 원문을 읽고 집필·검증한다. false는 보충 준비가 필요한 목록으로, 마제스틱에게 추가 수집 임무를 부여하지 않는다. 해당 차수의 준비 자료가 부족하면 보충 필요를 알리고 해당 회차를 건너뛴다.
- 한 파일당 한 기사로 만들지 않는다. 같은 사건·내용은 한 편으로 합치고 중복·비기사 대상은 근거와 함께 처리 상태를 남긴다. 아직 미확인인 자료를 전부 처리됐다고 표시하지 않는다.
- 다음 차수로 넘어가려면 현재 차수의 모든 준비 묶음에 발행/기보도 중복/기사화 제외 등 근거 있는 완료 판단이 있어야 한다. 접근 실패·자료 부족·검증 미완료는 완료가 아니라 보류다. 완료 근거가 불명확하면 차수 이동을 중단한다.
- 본문 첫 문단에 **전쟁부 제N차 공개자료 해설**을 표시하고, 확인한 공개일 및 사건일/문서 작성일을 구분한다. 제목에만 차수를 적고 본문에서 생략하지 않는다.
- 여러 차수를 대조할 필요가 있으면 보조 인용 각각의 차수·문서번호를 명시한다. 나중 차수의 내용을 미리 주제로 발행하지 않는다.
- 기존 주제 묶음 8개는 보조 참고서다. 당시 표시 순서나 우선순위로 6차부터 발행하지 않는다.
- 이 규칙은 새 기사 발행 또는 예약 생성 자체를 실행하지 않는다.
