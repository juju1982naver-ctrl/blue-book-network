## 마제스틱의 역할
준비된 주제 파일을 읽고 필요한 원문을 독해·검증해 독립적인 한국어 해설 기사를 쓴다. 포털 전체 목록을 다시 만들거나 이 목록을 보완하는 업무는 맡지 않는다. 해당 원문에 접근하지 못하거나 기사 근거가 부족하면 그 후보를 보류하고 준비된 다른 후보를 고른다. 사진 사용은 아래 운영자 확인에 따른다. 참고 주제 부족을 알리되 전수 수집 임무를 스스로 만들지 않는다.

## 발행 원칙

## 자료 사용 주의
공식 페이지는 AARO Comment와 후대 분석을 포함할 수 있다. 작성 당시 원문과 후대 해설을 구분한다. government-held 문서의 주장과 입증 사실을 구분한다. 원본 사진을 우선하고 실제 사진/영상, 재현 그림, 개념도, 썸네일을 구분한다. 사진 사용 목적과 제공 방식은 아래 운영자 확인에 따르며, 제3자의 사용 허가를 확보했다는 허위 표시는 하지 않는다.

## 범위
reference/는 비공개 참고 자료이며 공개 피드 생성 입력이 아니다. public/ 또는 content/approved/에 넣지 않는다. 이 커밋은 기사 생성·수정·삭제나 예약 생성을 포함하지 않는다. 자료는 연결된 GitHub에서 클라우드로 읽을 수 있으며 PC 실행을 요구하지 않는다. 새로운 공개 묶음의 수집·분류·보충은 별도의 준비 작업으로 다룬다.

## 운영자 확인: 개인 열람용 사진 사용
2026-10-22 운영자는 비상업적 개인 열람을 목적으로 원본 사진을 사용하도록 지시했고, 현재 Cloudflare 주소가 외부에서도 접근 가능한 구조라는 설명을 들은 뒤에도 사용 의사를 확인했다. 원본 사진을 활용하는 기준으로 준비하며 같은 사용 의사를 반복해서 묻지 않는다. 이는 운영자의 사용 목적과 지시를 기록한 것이며 제3자의 라이선스 허락이나 법적 판단을 확보했다는 뜻으로 쓰지 않는다.

실제 사건의 원본 사진·문서 화면을 우선하고 원문 주소·촬영자/제공자·날짜·크레딧을 표시한다. 실제 사진, 재현 그림, 개념도, 공식 미리보기를 정확히 구분하고 AI 이미지나 다른 사건 사진으로 대체하지 않는다. 공개 원본 링크를 활용할 수 있으며 접근 제한·유료 장벽을 우회하거나 비공개 개인 자료를 가져오지 않는다. 재사용 권리 확인이 끝나지 않은 자료를 '사용 허가 완료'로 표시하지 않는다. 사진의 허가 확인이 부족하다는 이유만으로 기사 전체를 일괄 보류하지 말고, 출처 링크를 제공하는 방법도 활용한다. 관련 주제 파일의 미디어 권리 미확인 표시는 확인 상태를 보존한 것이며 운영자에게 동일한 일반적 사용 승인을 다시 요청하라는 지시가 아니다.
